# Hi, I'm easy28 👋

I build small, honest developer tools that run **entirely in your browser** — real engines compiled to WebAssembly, no sign-up, no cookies, and zero data leaving your machine (open DevTools and check).

## The Honest Toolbox

- **[JSON Formatter App](https://jsonformatter.app)** — format, validate and transform JSON client-side: real jq 1.8 (WASM), JSONPath, diff, tree/table views, JSON→CSV/TypeScript/Python/Java/Rust/Go, and JSON Schema generate + validate
- **[RegexTester.dev](https://regextester.dev)** — a free online regex tester running **real regex engines via WebAssembly**: PCRE2, RE2, ECMAScript, Python, Go, Java, .NET, and Rust
  - Step-by-step pattern explainer and a backtracking debugger (with a flame graph of every backtrack step)
  - An [AI regex generator](https://regextester.dev/ai-regex-generator) that turns plain English into patterns
  - A [community gallery](https://regextester.dev/gallery) of 14,000+ real-world patterns with permalinks
  - A [compatibility checker](https://regextester.dev/compat) that flags where your pattern behaves differently across flavors
- **[SpeedPulse.tech](https://speedpulse.tech)** — an honest internet speed test that measures what actually ruins your calls and gaming: bufferbloat and latency under load, not just raw Mbps
